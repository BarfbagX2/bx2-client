# BX2

A Minecraft launcher and client for Windows: Minecraft: Java Edition from 1.8.9 to the newest
release with Fabric, Quilt, Forge, NeoForge or Legacy Fabric, BX2's optimization and quality-of-life
packs (every mod from its author's own Modrinth page, checked before it reaches your game), and
BX2 Native, a Rust edition of Minecraft 26.3.

## Download

The newest release is under [Releases](https://github.com/BarfbagX2/bx2-client/releases):
`bx2-launcher-setup.exe` installs it for your Windows account (no administrator needed). Each
release's `SHA256SUMS` is signed with BX2's release key, and the launcher updates itself only from
releases that carry a valid signature.

## What BX2 never does

- Start the game for an account that doesn't own it: you sign in with your own Microsoft account.
- See your password: you sign in on Microsoft's own page.
- Play for you: no aim help, no auto-clicking, nothing that changes how the game plays.
- Ship a mod it may not: mods download from their authors' own pages.
